------------------------------------------------
Using cpu device: GPU 없이 CPU로 학습 중이라는 뜻. 예상대로 정상.
Wrapping the env in a DummyVecEnv: SB3는 내부적으로 환경을 "여러 개 병렬로 돌릴 수 있는 형태(VecEnv)"로 항상 감싸서 처리해요. 
지금은 병렬 환경 1개만 쓰니까 가장 단순한 형태인 DummyVecEnv로 자동 래핑됐다는 안내입니다. 신경 안 쓰셔도 되는 내부 처리 로그예요.
Logging to ./tank_tensorboard/SAC_3: 이번 실행 로그가 SAC_3 폴더에 저장된다는 뜻. 
train.py를 여러 번 실행했다면 SAC_1, SAC_2, SAC_3처럼 번호가 자동으로 올라가요 (덮어쓰지 않고 매번 새 폴더 생성).


rollout/ 섹션 — 에피소드 성과 지표

ep_len_mean = 2e+03: 최근 에피소드들의 평균 길이가 2000 스텝이라는 뜻. TankEnv에서 max_episode_steps=2000으로 설정해뒀으니, 
이는 에피소드가 목표 도달이나 충돌 없이 시간 초과(truncated)로 계속 끝났다는 걸 의미해요. 아직 학습 초반이라 탱크가 목표에 도달하지도, 
딱히 부딪히지도 않고 그냥 헤매다가 시간이 다 된 거로 보입니다.
ep_rew_mean = -1.41e+03: 에피소드당 평균 누적 보상이 -1410 정도라는 뜻. 보상 함수가 reward = -0.01 * dist였으니, 
매 스텝마다 목표까지 거리에 비례해 계속 감점되다가 2000스텝 동안 쌓인 값이에요. 지금은 무작위에 가까운 초기 정책이라 마이너스로 크게 나오는 게 정상이고, 
학습이 진행되면서 이 값이 점점 0에 가깝게(또는 플러스로) 올라가는지가 핵심 관찰 포인트예요.

time/ 섹션 — 학습 속도 지표

episodes = 4: 지금까지 총 4번의 에피소드(리셋~종료)가 진행됐다는 뜻.
fps = 130: 초당 130스텝 처리 중이라는 뜻. 어제 추정했던 "50~150스텝/초" 범위 안에 잘 들어왔네요.
time_elapsed = 61: 학습 시작 후 61초 경과.
total_timesteps = 8000: 지금까지 총 8000스텝 진행됨. (설정한 10,000보다 적은 이유는 로그가 매 8000스텝마다 한 번씩 찍히는 주기라서 그래요. 
실제로는 10,000까지 다 돌고 마지막 로그 이후 완료된 거예요.)

train/ 섹션 — SAC 내부 학습 지표 (신경망 관련)

actor_loss = 7.65: 정책 신경망(Actor)의 손실값. SAC에서는 이 값 자체의 절대적인 크기보다 추세가 중요해요 (일정하게 튀지 않고 어느 정도 안정화되는지).
critic_loss = 0.000224: 가치 신경망(Critic)의 손실값. 매우 작은 값인데, 학습 초반이라 아직 큰 의미는 없어요.
ent_coef = 0.0935: SAC의 특징인 "엔트로피 보너스"에 곱해지는 계수. 탐험(무작위성)을 얼마나 유지할지를 자동으로 조절하는 값이에요. 학습이 진행되면서 보통 서서히 변화합니다.
ent_coef_loss = -7.95: 그 엔트로피 계수 자체를 학습시키는 손실값 (SAC는 이 계수도 자동으로 튜닝하도록 설계되어 있어요).
learning_rate = 0.0003: 신경망 업데이트 시 한 번에 얼마나 크게 값을 바꿀지 정하는 학습률. 기본값 그대로.
n_updates = 7899: 신경망이 지금까지 총 7899번 업데이트(경사하강법 1스텝)됐다는 뜻. 스텝 수와 거의 비슷한 횟수로 업데이트되는 게 SAC의 특징이에요 (매 환경 스텝마다 거의 한 번씩 학습).
